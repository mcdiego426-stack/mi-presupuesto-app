# Mi Presupuesto · app

Pantalla de la app de presupuesto personal, para abrir en pantalla completa desde el iPhone.

Aquí no hay datos: los números viven en una hoja de Google Sheets y solo se pueden leer
o escribir con la clave secreta del dueño (guardada solo en sus aparatos).

Se genera desde el proyecto privado `Presupuesto` (`node web/build.js`); no editar aquí a mano.
